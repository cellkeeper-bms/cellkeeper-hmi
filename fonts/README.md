# Fonts

The LCD UI's fonts are generated from these files by `tools/gen_ui_fonts.py`
(`components/hmi_ui/ui_fonts_data.cpp`).

| File | Font | Version |
|---|---|---|
| `Roboto-Regular.ttf`, `Roboto-Medium.ttf`, `Roboto-Bold.ttf` | Roboto | 3.015 |
| `RobotoMono-Regular.ttf` | Roboto Mono | 3.001 |

Both are licensed under the SIL Open Font License, Version 1.1: see `OFL.txt` in this folder.
The files are unmodified copies from Google Fonts. The rest of this repository is under the
